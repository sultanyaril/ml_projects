# Disaster Prediction by Tweets

Purpose
- Pipeline and experiments for classifying disaster-related tweets (NLP).

Quick run
- Open the Jupyter notebook `Disaster Prediction by Tweets.ipynb` for data processing, feature engineering and model experiments.

Key files
- `Disaster Prediction by Tweets.ipynb` — main notebook with EDA, feature engineering, model experiments and plots.
- `train.csv`, `test.csv`, `sample_submission.csv` — dataset files (if present).

Notes
- Experiments include word embeddings and dense models. A BERT-based rewrite was attempted but not completed.
