# Flappy Bird RL

Purpose
- Reinforcement learning experiments for Flappy Bird using different feature sets and agents.

Quick run
- Inspect notebooks (`*.ipynb`) or `run_*.py` scripts to reproduce experiments.
- GIFs and saved weights are in the `gifs/` and `weights/` folders for quick inspection.

Key files
- `run_simple.py`, `run_12.py`, `run_8million.py` — scripts to run training/evaluation.
- `flappy_bird_gym/` — environment package and helper modules.
- `gifs/` — recorded agent behaviour GIFs.
- `weights/` — saved model weights.

Notes
- RGB experiments require `pygame` for rendering and may be slow on low-spec machines.
